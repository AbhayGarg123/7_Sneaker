# Thala 7 — Footwear Storefront

A clean, multi-section footwear storefront for showcasing a featured shoe and presenting the shopping and checkout experience. Built with HTML and CSS, this project is a lightweight front-end demo with no build tools or package installation required.

## Features

- Landing page with a hero section, product promotion, and service highlights.
- Featured product page with product details, pricing, a quantity display, and an image gallery.
- Shopping cart layout with product rows, coupon entry, and an order summary.
- Checkout layout with contact and payment form fields.
- Custom cart and payment graphics from the local assets folder.
- Responsive styling for supported screen sizes.

## Pages and Sections

The storefront sections are currently presented together in `index.html`:

1. **Home** — branded hero and store highlights.
2. **Product** — featured shoe details and gallery.
3. **Cart** — cart items and order summary.
4. **Checkout** — contact details, payment options, and order summary.

The Shop Now link points to `product.html`, which is not included in this project yet. To keep browsing within the current page, update that link to the product section or add the corresponding page.

## Tech Stack

- HTML5
- CSS3
- Local image assets (PNG and JPG)

## Run Locally

1. Download or clone this repository.
2. Keep `index.html`, `style.css`, and the `images/` folder together.
3. Open `index.html` in a web browser.

No dependencies, build step, or server are required.
